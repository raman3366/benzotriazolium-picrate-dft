# Tables of the BTPC paper (benzotriazolium picrate, paper id `btpc`)

Generated by `scripts/tables/make_tables.py` together with the tables; do not edit by hand. Rebuild with
`python scripts/tables/make_tables.py --check` from the repository root (docs/REPRODUCE.md).

Each `<stem>.md` holds one pandoc pipe table, then the caption line `Table: … {#tbl:<stem>}`, whose last sentences are the notes and footnotes of the table (round 1, figures_r1 #1). Insert a table into a manuscript with the include line given below; the path is relative to the manuscript: `papers/btpc/manuscript.md` uses `tables/<stem>.md`, the SI (`papers/btpc/si/manuscript.md`, built with the `S` number prefix) uses `../tables/<stem>.md`. Cite a table as `@tbl:<stem>` (for example `@tbl:tbl_geometry` → "Table 2"). The only cross-references inside the tables are the equation references `@eq:chi_eta` and `@eq:s_omega` in the note of `tbl_fmo_descriptors`, which resolve in the main text where that table sits; every other file builds in either document.

**SI order matters.** The SI numbers below assume the SI includes the tables in this order. The draft caption of `figS_mep_extrema` (PLAN.md §4) calls the extremum table "Table S5"; keep `tblS_mep_extrema` fifth or change that caption.

## Deviations from PLAN.md (§5, §6) and why

1. Location and naming follow the task, not PLAN.md §2: script `papers/btpc/tables/make_tables.py`, outputs `papers/btpc/tables/<stem>.md`, label `{#tbl:<stem>}` (so `@tbl:tbl_geometry`, `@tbl:tblS_coords`), caption line after the table; since the round-1 revision the notes and footnotes are sentences of the caption, so that they are not set as line-numbered body text (figures_r1 #1).
2. Precision of agreement statistics: bond RMSD/MAE 4 decimals and angle RMSD 2 decimals (as in the figure legends), because 3 and 1 decimals would print the two models as identical. Everything else follows STYLE.md.
3. Table 3: the proton asymmetry d(H···O1) − d(N4–H4N) is in the footnote, not an extra row (it does not fit the D–H / H···A / D···A columns); all three values come from `*.nh_minus_ho_asym` (X-ray key added to facts.json after QA round 2). Crystal-only contacts N6–H6N···O6 and C9–H9···O5 are single "X-ray only" rows instead of rows with "absent" model cells.
4. Table 4: an electronic-energy row was added (so that H − E and G − E can be read); the three lowest wavenumbers carry 1 decimal (3.2i), the N–H wavenumbers and red shifts are integers, as quoted in the text (figures_r1 #15). Thermal terms in kcal mol⁻¹ with the quasi-RRHO entropy beside the harmonic one; the absolute *H* and *G* moved to the caption of Table S1 (referee m7). The imaginary-mode check with the 0.005 Bohr step and the PySCF count are in Section 2.4 of the paper and in Table S8; footnote a points to them (round 2, figures_r2 #6).
5. Table 6: a derived row "Character of the HOMO–LUMO gap" (within the picrate / picrate → cation) was added, from the picrate shares of HOMO and LUMO.
6. Table 5: no column with the type labels of the spike search (they are thresholds on sign(λ₂)ρ, PLAN footnote); gas spikes 1–3 (same atoms, same region, same sign) are merged into one row with footnote a; the matching real-space region is found automatically: its lowest-RDG point lies between the same atom pair as the spike (or, if no region does, next to one of its atoms) and its sign(λ₂)ρ range overlaps the bin.
7. Table S1 (`tblS_coords`): one table with the IEF-PCM and gas-phase coordinates side by side instead of parts (a) and (b); no element column (the CIF label starts with the element symbol).
8. Table S2 (`tblS_frequencies`): columns Mode | gas phase | assignment (gas phase) | IEF-PCM 0.01 Bohr | IEF-PCM 0.005 Bohr | assignment (IEF-PCM) (gas phase first since the round-1 revision): two assignment columns because mode k is a different vibration in each model. 9. Table S4 (`tblS_bonds_angles`): every value is computed from the coordinate files with the connectivity rule of build_facts.py; instead of flagging derived cells, the script checks every cell that also exists as a facts key (28 bonds, 4 angles) and reproduces the four RMSD keys to 1e-9.
10. Table S8 (`tblS_pcm_trajectory`): the absolute-energy column is replaced by ΔE (kcal mol⁻¹, 3 decimals, relative to the final step, whose absolute energy is given in the footnote), because nine columns do not fit the text width in the PDF build; every header carries its unit (round 2, figures_r2 #6). The imaginary-mode checks are in the footnotes rather than in rows below the table.
11. Table S9 (`tblS_protocol`): settings are reworded without internal code paths; the host machine is omitted; every number still comes from `protocol.*` / `software.*` / `model.*` and is checked against them.
12. Column widths: pandoc takes relative widths from the dash counts of the separator line. The script sizes each column by its widest body cell (at least the longest word of its header) and sets explicit widths for Tables 7, S2 and S6, so that the PDF build (lualatex, 16 cm text) has no overfull cells and the DOCX has the same proportions.
